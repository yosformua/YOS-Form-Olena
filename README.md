# Olena Sychova — сайт-портфоліо (макет)

Робочий макет одностраничного сайта-визитки дизайнера інтер'єрів
з окремими сторінками проєктів і перемиканням мов через JSON.

## Структура

```
site/
├── index.html          — головна сторінка (Hero → About → Portfolio → Process → Contact)
├── project.html         — шаблон сторінки окремого проєкту (?id=slug)
├── css/
│   └── styles.css       — усі стилі
├── js/
│   ├── i18n.js           — рушій перемикання мов
│   ├── app.js             — рендер і фільтрація карток портфоліо
│   └── project.js         — рендер сторінки проєкту
├── lang/
│   ├── uk.json            — українська (мова за замовчуванням)
│   ├── ru.json             — російська
│   └── en.json             — англійська
├── data/
│   └── projects.json       — дані по проєктах (назва, рік, локація, опис на 3 мовах, фото)
└── assets/img/              — фото (витягнуті з презентації-оригіналу)
```

## Як запустити локально

Відкрити `index.html` подвійним кліком НЕ спрацює коректно (fetch не працює
з `file://`). Потрібен локальний сервер, наприклад:

```bash
cd site
python3 -m http.server 8000
```

Потім відкрити http://localhost:8000 у браузері.

Або будь-яким іншим локальним сервером (VS Code Live Server,
`npx serve`, тощо).

## Як міняти тексти (без чіпання HTML/JS)

Усі тексти інтерфейсу лежать у `lang/uk.json`, `lang/ru.json`, `lang/en.json`.
Структура ключів однакова у всіх трьох файлах — просто заміни значення
праворуч від `:`, ключі (зліва) не чіпай.

Приклад:
```json
"hero": {
  "title": "Твій новий заголовок тут"
}
```

Перемикач мов у шапці сайту (UA / RU / EN) підхоплює зміни автоматично
після перезавантаження сторінки. Обрана мова запам'ятовується в браузері
(localStorage), а за першого візиту сайт намагається визначити мову
з налаштувань браузера користувача.

## Як додати/змінити проєкт у портфоліо

Відкрий `data/projects.json` — це масив об'єктів. Скопіюй один блок
і зміни поля:

```json
{
  "id": "унікальний-slug-для-url",
  "category": "architecture | residential | commercial",
  "title": "Назва проєкту",
  "year": "2025",
  "location": "Україна, м. ...",
  "cover": "assets/img/твое-фото.jpg",
  "gallery": ["assets/img/фото1.jpg", "assets/img/фото2.jpg"],
  "description": {
    "uk": "Опис українською",
    "ru": "Опис російською",
    "en": "Опис англійською"
  }
}
```

Картка автоматично з'явиться в сітці портфоліо і відкриє власну сторінку
`project.html?id=унікальний-slug-для-url`.

Фото додавай у `assets/img/` — рекомендований формат JPG, ширина
до 1600px для карток і до 2200px для hero-зображень (для швидкого
завантаження на мобільних).
